# 콘텐츠 작성 규칙 (AI 검색 최적화 + 중복 방지)

모든 콘텐츠 세트는 아래 규칙을 따른다.

## 1. AI 검색 최적화 (네이버 AI 브리핑, 구글 AI 오버뷰)

- **제목은 검색 질문 그대로**: 사용자가 실제로 검색창/AI에 묻는 문장형으로 쓴다.
  - ❌ "불당드림치과의 임플란트 안내"
  - ✅ "임플란트 치과 어떻게 골라야 할까? 확인해야 할 3가지"
- **두괄식 핵심 답변**: 글 시작 3줄 안에 질문에 대한 직접 답변을 넣는다. AI가 이 부분을 인용한다.
- **Q&A 블록**: 소제목을 질문형으로 쓰고, 첫 문장에서 바로 답한다.
- **FAQ 섹션**: 글 끝에 자주 묻는 질문 2~4개를 넣는다 (스키마와 연동).
- **수치·조건 명시**: "약 2~6개월", "최소 5회 내원" 같은 구체 수치가 AI 인용 확률을 높인다.

## 2. 스키마 (구글 블로그 버전)

JSON-LD `<script type="application/ld+json">`로 삽입:
- `MedicalWebPage` 또는 `Article` — 제목, 설명, 작성자(병원), 날짜
- `FAQPage` — 본문 FAQ 섹션과 동일한 질문/답변
- `Dentist`(LocalBusiness) — 병원명, 주소, 전화, 지역

네이버 블로그는 스크립트 삽입이 불가하므로 **구조로 대신한다**: 질문형 소제목 + 두괄식 답 + FAQ 섹션 (네이버 스마트블록/AI 브리핑이 이 구조를 추출).

## 3. 채널 간 중복 방지 (동일 문서 발행 금지)

같은 주제라도 네이버/구글 버전은 **서로 다른 문서**로 작성한다. 검색엔진이 중복 문서로 판정하면 한쪽이 색인 누락된다.

| 항목 | 네이버 버전 | 구글 버전 |
|---|---|---|
| 제목 | 서로 다르게 (같은 키워드, 다른 문장) | |
| 구성 | 경험담·상담 사례 중심, 대화체 | 정보 정리형, 개조식 |
| 문장 | 전면 재작성 — 문단 단위 복붙 금지 | |
| 도입/마무리 | 각각 새로 작성 | |

- 두 버전 간 **연속 2문장 이상 동일 금지**.
- 스레드는 요약이므로 자유롭게 재구성하되 블로그 문장 복붙 금지.

## 4. 의료광고법

- 효과 보장·최상급 표현 금지: "최고", "100%", "완치", "무통", "부작용 없음"
- 치료 전후 사진은 조건(개인차) 명시
- 글 하단에 개인차 고지 문구 필수
