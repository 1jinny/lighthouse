# SEO Article Publisher — 블랑쉬치과

블랑쉬치과의원(강남/논현역) 기준으로 SEO 글을 가공·발행하는 프로그램.

## 구조

```
seo-publisher/
├── config/
│   └── clinic-profile.json   # 병원 정보, 타겟 키워드, 톤 가이드
├── articles/
│   ├── input/                # 원본(긁어온) 글을 여기에 넣음
│   └── output/               # SEO 최적화된 결과물
└── README.md
```

## 파이프라인 (예정)

1. **입력**: `articles/input/`에 원본 글 저장 (마크다운/텍스트/HTML)
2. **가공**: 병원 프로필 + 타겟 키워드 기반으로 SEO 최적화
   - 제목/소제목 키워드 배치, 메타 설명 생성
   - 의료광고법 준수 검토 (과장·보장 표현 제거)
   - 병원 정보(위치, 연락처) 자연스럽게 삽입
3. **발행**: 대상 플랫폼 API로 업로드 (플랫폼 확정 후 구현)
