# 불당드림치과 AI 인용(GEO) 액션 플랜

목표: 구글 AI 오버뷰/AI 모드, 네이버 AI 브리핑, ChatGPT 등 AI 검색이
"천안 치과", "임플란트 기간" 같은 질문에 답할 때 **불당드림치과 콘텐츠를 인용·추천**하게 만든다.

체크리스트(OPENSCHEMA 테크니컬 SEO) 항목 번호를 함께 표기.

---

## 1순위 — AI가 읽을 수 있게 만들기 (크롤러빌리티)

| 할 일 | 관련 항목 | 이유 |
|---|---|---|
| robots.txt에서 AI 크롤러 허용 확인: `GPTBot`(ChatGPT), `Google-Extended`(Gemini/AI오버뷰 학습), `ClaudeBot`, `PerplexityBot`을 차단하고 있지 않은지 | #6 | 차단되어 있으면 AI 인용 자체가 불가능. 보안 플러그인·호스팅 기본값이 봇을 막는 경우가 흔함 |
| 해외 IP 차단 해제 확인 | #88 | 구글 크롤러와 AI 크롤러 대부분 미국 IP에서 출발. 국내 호스팅이 해외 IP를 막아두면 사이트 전체가 크롤 불가 |
| sitemap.xml 생성 + lastmod 정확히 유지 + 서치콘솔 제출 | #2, #3, #5 | AI는 최신성 신호를 크게 반영. lastmod가 정확하면 갱신된 콘텐츠가 빨리 재수집됨 |
| RSS/Atom 피드 제공 | #4 | 체크리스트에도 명시: 피드는 OpenAI 계열의 콘텐츠 발견 경로. 블로그형 콘텐츠 섹션에 피드 필수 |
| 5xx 에러·서버 응답속도(TTFB 200ms 이하) 점검 | #87, #89, #10 | 느린 서버는 크롤 빈도 자체가 줄어 인용 기회 감소 |

## 2순위 — AI가 이해할 수 있게 만들기 (구조화)

| 할 일 | 관련 항목 | 이유 |
|---|---|---|
| `Dentist`(LocalBusiness) 스키마: 병원명·주소·전화·진료시간·진료권역 | #36, #75 | AI가 "천안 불당동 치과" 질문에 지역 엔티티로 매칭하는 근거 |
| 진료 안내 페이지에 `MedicalWebPage` + `FAQPage` 스키마 | #36 | 질문-답변 쌍은 AI가 가장 인용하기 쉬운 형태 |
| 원장 프로필 페이지 + `ProfilePage`/`Physician` 스키마 (본명, 자격, 약력) | #76, #77 | 치과는 YMYL(건강) 영역 — AI는 작성자 신뢰도가 확인되는 의료 콘텐츠를 우선 인용 |
| 브래드크럼 + 구조화 데이터 | #32 | 사이트 구조 이해도 향상 |
| 스키마는 페이지당 하나로 nest(통합)해서 작성 | #38 | 분산된 스키마는 관련성 해석이 약해짐 |
| 구글 비즈니스 프로필 등록·정보 일치 | #75 | AI 지역 추천은 비즈니스 프로필 + 리뷰를 강하게 참조 |

## 3순위 — AI가 인용하고 싶은 콘텐츠 만들기

| 할 일 | 관련 항목 | 이유 |
|---|---|---|
| 질문형 제목 + 첫 3줄 내 직접 답변 (두괄식) | #47, #53 | AI는 질문에 대한 '즉답 문단'을 추출해 인용 |
| 구체적 수치 포함: "약 2~6개월", "5~6회 내원" | - | 수치가 있는 문장이 인용 확률이 높음 (이미 콘텐츠 가이드라인에 반영됨) |
| 페이지별 고유 title/description, 중복 회피 | #47, #48, #90 | 정형문 반복은 페이지 고유성을 희석 |
| 네이버 블로그·Blogger·스레드와 병원명/주소/전화(NAP) 완전 일치 | #75 | AI는 여러 출처에서 교차 확인되는 정보를 신뢰 |
| 콘텐츠 정기 갱신 (오래된 글 업데이트 + lastmod 반영) | #3, #86 | 시의성 있는 심층 콘텐츠가 디스커버·AI 노출 우선순위 |
